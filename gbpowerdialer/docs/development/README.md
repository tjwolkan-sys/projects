# Geliştirme Ortamı

Bu klasör, gbpowerdialer için local development, IDE, build ve debug akışlarını tarif eder. Buradaki dokümanlar production runtime contract'ı değil, geliştirici çalışma ortamı standardıdır.

- `DEVELOP-BRANCH-SYNC.md`: Feature/fix branch'lerini PR öncesi remote `origin/develop` ile güvenli sync etme standardı.
- `VS-CODE-DEVELOPER-SETUP.md`: Yeni developer için VS Code, Maven, Tomcat ve local tool path kurulum adımları.
- `VS-CODE-TOMCAT-DEBUG.md`: VS Code ile Maven WAR build, Tomcat deploy ve Java attach debug standardı.
