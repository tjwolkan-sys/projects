### 2026-06-29 09:13:31 +03:00 | 321997 | callback-attempt-counter-fixes

**Kapsam**

FEAT-321997 ATTEMPT_COUNT reschedule mantığında saha testinde bulunan iki bug'ın kök-neden düzeltmesi (campaign 115 / Elif test logları + DB result görseli). `CampaignDbOperations.rescheduleAppointedCallback` sunucu-tarafı CASE UPDATE'i hedef alır.

1. **NULL-safe sayaç (callback kurmuyor):** Result tablosundaki `callback_attempts` kolonu NULL iken (callback'i kuran disposition 0'a set etmiyor, eski satırlar NULL) çıplak kolon kullanımı patlıyordu: optimistic guard `callback_attempts = expectedOld(0)` NULL satırı eşleştirmiyor (`NULL = 0` → unknown) ve aritmetik `NULL + 1 = NULL`. Sonuç: UPDATE 0 satır → `is_fetched` dolu kalıyor → callback bir daha fetch edilmiyor/dial edilmiyor/havuza düşmüyor (sonsuza dek takılı = "callback kurmuyor"). Log kanıtı: `... callback_attemps = CASE WHEN callback_attemps + 1 >= 2 ... WHERE id IN (166125) AND callback_attemps = 0` → 0 satır.

2. **Off-by-one (convert AFTER N attempts):** Eşik karşılaştırması `callback_attempts + 1 >= threshold` ile yapılıyordu; bu sayacı eşiğin BİR ALTINDA (N-1) convert edip 0'a sıfırlıyor, sayaç eşik değerine (N) hiç ulaşmıyordu. Kullanıcı gözlemi: agentCbConvertAfterAttempts=4 iken sayaç 1,2,3 olup 4'e ulaşmadan sıfırlanıyor ("sanki 4 değil 3 deniyor").

**Değişiklikler**

- `gbpowerdialer/src/main/java/com/powerdialer/engine/db/CampaignDbOperations.java` (`rescheduleAppointedCallback`):
  - Tüm `callback_attempts` referansları `COALESCE(<col>, 0)` ile sarıldı (hem CASE aritmetiği `... + 1` hem WHERE optimistic guard) → NULL satırlar 0 kabul edilir; ilk reschedule NULL→1 yapar.
  - Eşik koşulu `COALESCE(col,0) + 1 >= threshold` → `COALESCE(col,0) >= threshold` (ESKİ sayaç ile karşılaştırma, "+1" kaldırıldı). Böylece sayaç 1..N'e GÖRÜNÜR biçimde ulaşır; bir sonraki tetiklemede (eski sayaç >= eşik) THEN dalında user_id=NULL + callback_date=now + sayaç=0 ile havuza devredilir. ELSE dalı sayacı `COALESCE(col,0)+1` ile artırmaya devam eder. Davranış: "convert AFTER N attempts".
