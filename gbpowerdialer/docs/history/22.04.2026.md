## VS Code Tomcat Shutdown Port Düzeltmesi

### Bağlam

VS Code debug task'ı WAR deploy edip Tomcat'i başlattıktan sonra debug oturumu kısa süre içinde kapandı. Loglarda Tomcat'in `8005` shutdown portunu açamadığı ve `Address already in use` nedeniyle kendini durdurduğu görüldü. `netstat` çıktısında `8005` portunun PID 4/System tarafından tutulduğu doğrulandı.

### Yapılanlar

- VS Code Tomcat script'i generated `CATALINA_BASE` kullanacak şekilde güncellendi.
- Default generated base `.vscode/.local/tomcat-base` olarak belirlendi ve bu klasör `.gitignore` kapsamında bırakıldı.
- Generated `server.xml` içinde shutdown port default `18005`, HTTP port default `18080` olacak şekilde düzenleniyor.
- Script start öncesi debug, HTTP ve shutdown portlarının boş olduğunu kontrol ediyor.
- Script artık HTTP portu hazır olana kadar bekliyor ve hazır olduğunda browser'ı `http://localhost:18080/gbpowerdialer/` adresinde açıyor.
- `TOOL-PATHS` şablonuna `TOMCAT_BASE`, `TOMCAT_HTTP_PORT`, `TOMCAT_SHUTDOWN_PORT` ve `TOMCAT_OPEN_BROWSER` anahtarları eklendi.

### Kararlar

- VS Code task'ı developer'ın Tomcat install klasöründeki `conf/server.xml` dosyasını değiştirmeyecek.
- Shutdown portu `8005` yerine repo-local generated base içinde `18005` kullanılacak.
- `5005` yalnızca JDWP debug portudur; browser kontrolü için HTTP portu ve context path kullanılır.

## VS Code HTTP Port ve Deploy Base Düzeltmesi

### Bağlam

VS Code generated base'e geçtikten sonra task, HTTP port `8080` için çakışma raporladı. Kontrolde `8080` için gerçek LISTENING process görünmedi; netstat fallback'i uzak portu veya `TIME_WAIT` satırını yanlış pozitif yakalayabiliyordu. Ayrıca deploy hedefi generated `CATALINA_BASE/webapps` yerine Tomcat install `webapps` klasörünü kullanmaya devam ediyordu.

### Yapılanlar

- VS Code Tomcat default HTTP portu `18080` olarak değiştirildi.
- Local tool path dosyasında `TOMCAT_HTTP_PORT=18080` yapıldı.
- Port kontrolü yalnızca local LISTENING portları yakalayacak şekilde daraltıldı.
- Tomcat stop komutu, shutdown port dinlemiyorsa gürültülü `Connection refused` üretmeden skip edecek şekilde değiştirildi.
- WAR deploy hedefi generated `CATALINA_BASE/webapps` olarak düzeltildi.
- Browser açılışı Java attach'in başlaması için birkaç saniye gecikmeli hale getirildi.

### Kararlar

- IntelliJ/Tomcat akışı `8080` üzerinde kalabilir.
- VS Code Tomcat akışı `18080` HTTP, `18005` shutdown ve `5005` debug portlarını kullanır.
