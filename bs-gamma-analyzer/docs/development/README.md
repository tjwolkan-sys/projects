# Geliştirme Ortamı

Bu klasör, bs-gamma-analyzer için local development, IDE, build ve debug akışlarını tarif eder. Buradaki dokümanlar production runtime contract'ı değil, geliştirici çalışma ortamı standardıdır.

- `LOCAL-SETUP.md`: Yeni developer için ortam kurulum adımları (Python, virtualenv, pip, PostgreSQL erişimi, Anthropic API key kullanımı).
- `VS-CODE-DEVELOPER-SETUP.md`: VS Code üzerinde Streamlit ve pytest debug ayarları.
- `MAIN-BRANCH-SYNC.md`: `origin/main` ile güvenli sync, PR conflict riski raporlama akışı.
